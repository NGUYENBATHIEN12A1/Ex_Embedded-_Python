Part 1 — ESP32 firmware (MicroPython)

The firmware runs on the ESP32. When the board powers up, MicroPython runs boot.py first and then main.py. main.py uses sensors.py to read the sensors, and sensors.py uses the two drivers in lib/.

boot.py ──► wifi.py                      (connect Wi-Fi, sync the clock)
main.py ──► wifi.py, sensors.py, umqtt   (main loop)
sensors.py ──► lib/bmp180.py, lib/bh1750.py, dht (built in)
config.py  ◄── every file reads its settings from here

Click a line number (for example L14) to open that exact line in VS Code. In the HTML version, VS Code may ask once to allow opening the link.

1.5. lib/bmp180.py — pressure sensor driver

The BMP180 does not output °C and Pa directly. It returns raw values (UT, UP) that must be converted with the datasheet formulas and 11 calibration coefficients unique to each chip (written into it at the factory).

LinesCodeExplanation
L2–3
2import struct3import time
struct to unpack bytes into numbers, time for delays.
L5–8
5_REG_CALIB = 0xAA6_REG_ID = 0xD07_REG_CTRL = 0xF48_REG_DATA = 0xF6
Register addresses: 0xAA calibration data, 0xD0 chip ID, 0xF4 measurement command, 0xF6 result.
L9
9_CHIP_ID = 0x55
The BMP180 chip ID is always 0x55.
L10–11
10_CMD_TEMP = 0x2E11_CMD_PRES = 0x34
"Measure temperature" (0x2E) and "measure pressure" (0x34) commands.
L12
12_PRES_WAIT_MS = (5, 8, 14, 26)   # theo oversampling 0..3
Pressure conversion time for oversampling modes 0–3: more precise means slower, 5 → 26 ms.
L15–18
15def _div(a, b):16    # Phép chia số nguyên làm tròn về 0 như trong C (datasheet dùng C).17    q = abs(a) // abs(b)18    return q if (a >= 0) == (b >= 0) else -q
_div(): integer division that rounds toward zero, like C. Python's // rounds down (-7 // 2 = -4, while C gives -3). The datasheet formulas are written in C, so this is needed to get identical results.
L21–23
21def compensate(cal, ut, up, oss):22    """Tính (nhiệt độ °C, áp suất Pa) từ giá trị thô. cal = 11 hệ số hiệu chuẩn."""23    ac1, ac2, ac3, ac4, ac5, ac6, b1, b2, _mb, mc, md = cal
compensate(): unpack the 11 coefficients (ac1 … md; _mb is unused).
L24–27
24    x1 = ((ut - ac6) * ac5) >> 1525    x2 = _div(mc << 11, x1 + md)26    b5 = x1 + x227    temp = ((b5 + 8) >> 4) / 10
Temperature, per the datasheet. >> 15 shifts right 15 bits, i.e. divides by 2¹⁵. b5 is an intermediate value reused for pressure. The result is in 0.1 °C, hence / 10.
L29–46
29    b6 = b5 - 400030    x1 = (b2 * ((b6 * b6) >> 12)) >> 1131    x2 = (ac2 * b6) >> 1132    x3 = x1 + x233    b3 = _div(((ac1 * 4 + x3) << oss) + 2, 4)34    x1 = (ac3 * b6) >> 1335    x2 = (b1 * ((b6 * b6) >> 12)) >> 1636    x3 = (x1 + x2 + 2) >> 237    b4 = (ac4 * (x3 + 32768)) >> 1538    b7 = (up - b3) * (50000 >> oss)39    if b7 < 0x80000000:40        p = _div(b7 * 2, b4)41    else:42        p = _div(b7, b4) * 243    x1 = (p >> 8) * (p >> 8)44    x1 = (x1 * 3038) >> 1645    x2 = (-7357 * p) >> 1646    p = p + ((x1 + x2 + 3791) >> 4)
Pressure, following the datasheet steps exactly (section 3.5): b6 → b3 → b4 → b7 → p. L39–42 splits two cases to avoid 32-bit overflow, as in the C original. L43–46 is the final non-linear correction. The result p is in Pa.
L47
47    return temp, p
Return (°C, Pa). A unit test checks this against the datasheet example: exactly 15.0 °C and 69 964 Pa.
L50–51
50def altitude(pressure_hpa, sea_level_hpa=1013.25):51    return 44330.0 * (1.0 - (pressure_hpa / sea_level_hpa) ** (1 / 5.255))
altitude(): barometric formula h = 44330 × (1 − (p/p₀)^(1/5.255)).
L54–58

BMP180 class: stores the I2C bus, the address and oss = 3 (highest precision, lowest noise).
L59–61

Read the chip ID; anything other than 0x55 raises "BMP180 not found".
L62

Read 22 bytes of calibration data and unpack them into 11 16-bit numbers. In ">hhhHHHhhhhh", > means big-endian (high byte first), h is signed and H unsigned.
L64–68
64    def _raw_temp(self):65        self.i2c.writeto_mem(self.addr, _REG_CTRL, bytes([_CMD_TEMP]))66        time.sleep_ms(5)67        d = self.i2c.readfrom_mem(self.addr, _REG_DATA, 2)68        return (d[0] << 8) | d[1]
_raw_temp(): start a temperature conversion, wait 5 ms, read 2 bytes and combine them into a 16-bit number (high << 8 | low).
L70–74
70    def _raw_pressure(self):71        self.i2c.writeto_mem(self.addr, _REG_CTRL, bytes([_CMD_PRES + (self.oss << 6)]))72        time.sleep_ms(_PRES_WAIT_MS[self.oss])73        d = self.i2c.readfrom_mem(self.addr, _REG_DATA, 3)74        return ((d[0] << 16) | (d[1] << 8) | d[2]) >> (8 - self.oss)
_raw_pressure(): start a pressure conversion with the oss setting, wait, read 3 bytes and combine them into a 19-bit number.
L76–79

1.8. lib/umqtt/simple.py

This is the official MicroPython MQTT library (micropython-lib, MIT licence), not code written for this project. It only needs copying to the board if the firmware does not already include it. The functions the project uses:

FunctionWhat it does
set_last_will()Registers the "last will" (LWT) message.
connect()Opens a TCP socket to the broker and sends CONNECT.
publish()Sends a message; with QoS 1 it waits for the PUBACK confirmation.
subscribe()Subscribes to a topic.
check_msg()Checks for an incoming message without waiting; calls the callback if there is one.
ping()Sends PINGREQ to keep the connection alive.
disconnect()Disconnects cleanly (the broker then does not publish the LWT).
